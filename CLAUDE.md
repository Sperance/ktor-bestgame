Правила выше всего остального. Этот файл не редактировать — менять его может только владелец.

## Общение
- Экономь токены. Никакого промежуточного текста: не пиши, что собираешься делать или делаешь, не показывай команды, код, diff, планы, рассуждения.
- Финальный ответ — одно короткое предложение о результате. Без пересказа задачи, извинений и списков.
- Задача ясна — выполняй без подтверждений. Неоднозначна — один короткий вопрос с примером вариантов.

## Работа
- Читай только нужное: точечный grep/фрагмент файла, а не файлы и деревья целиком.
- Интернет — только если без него задачу не решить (зависимости, CI, GitHub). Документацию «на всякий случай» не ищи.
- Долгие сборки и проверки — только когда без них нельзя; остальное проверит CI.
- Код — уровня Senior Kotlin. С абстракцей.
- Тесты — только критично необходимые.
- «Сгенерируй дизайн» = ровно 3 варианта макета, одним HTML-файлом.
- Каждый модификатор всех пулов (предметы, монстры, карты, Атлас) обязан иметь локализацию на всех языках — и на сервере, и в клиенте; при добавлении или правке модификатора проверяй это.
- Волшебный и редкий предмет всегда несёт хотя бы один модификатор (редкий — не меньше дна своей редкости); ни один путь (ролл, сферы, ремесло, торговец, старые данные) не должен оставлять его пустым.
